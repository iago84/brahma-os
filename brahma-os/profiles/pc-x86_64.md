# Perfil — PC x86_64 (escritorio)

| Campo | Valor |
|---|---|
| Base | Kubuntu / KDE Plasma (LTS) — candidata |
| Kernel / Boot | kernel de la distro · GRUB o sd-boot · BIOS + (U)EFI |
| Shell / UI | KDE Plasma + BRAHMA DESKTOP (React+Vite+TS) + Qt6/QML (posterior) |
| Imagen | ISO híbrida (live + instalador) |
| Toolchain | **live-build** (alt.: Cubic / mkosi) |
| Salida | `brahma-os-pc-amd64.iso` |
| Estado | Diseño (sin ISO construida) |

## Pasos previstos

1. Base Kubuntu/KDE validada en VM (QEMU) antes de cualquier ISO.
2. Perfil de paquetes: `base/packages/base.list` + `desktop-pc.list` + `services.list`.
3. Integración CORE/DESKTOP como unidades (user/system), `BRAHMA_AI_ENABLED=false`.
4. Receta reproducible (`iso/build.sh --profile pc`).
5. Branding/first-boot + recovery.
6. SBOM/licencias → pruebas VM → hardware real.

## Requisitos / bloqueos

- Autorización para instalar toolchain y construir/arrancar la ISO.
- Validación de arranque BIOS **y** UEFI.
